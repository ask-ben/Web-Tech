Bold makes the text bold.

Important text defines text with strong importance. The content inside is typically displayed in bold.

Italic text defines a part of text in an alternate voice or mood.

Emphasized text defines emphasized text.

Marked text defines text that should be marked or highlighted.

Small text defines smaller text.

Deleted text defines text that has been deleted from a document.

Inserted text defines text that has been inserted into a document. Browsers will usually underline inserted text.

Subscript text defines subscripted text.

Superscripted text defines superscripted text.
